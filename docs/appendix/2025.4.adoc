== 2025.4

=== 2025.4.0

We improved the decoding of Cypher Unicode escapes and in the process, the sanitiser produces slightly different output now for three cases:

* `x\\n` now produces the literal `x\n`,
* `\u005C\u005C` produces two backslashes
* `x\\u0060y` produces the literal `x\u0060y`

All variants will be safely sanitized for Cypher of course. These are some edge-cases, but we felt that a minor bump is in order. No other functional or API changes.
